# 🗺️ Village Asset Mapping System

## GIS-Enabled Community Asset Management Platform

The **Village Asset Mapping System** is a web-based GIS application designed to digitally map, visualize, and manage important community assets within a village.

The system helps users locate and access information about facilities such as schools, healthcare centres, water tanks, roads, government buildings, and other public infrastructure through an interactive map.

---

## 🎯 Main Objective

The main objective of this project is to develop a simple and user-friendly digital platform that helps communities and local administrators:

- Locate important village assets
- View assets on an interactive map
- Search for specific facilities
- Filter assets by category
- View basic asset information
- Understand the geographical distribution of resources
- Support better village planning and infrastructure management

---

## ❗ Problem Statement

Village infrastructure information is often maintained through paper records, separate documents, or local knowledge. This can make it difficult to quickly locate facilities and understand their geographical distribution.

The proposed system provides a centralized digital platform for storing, mapping, and visualizing community assets.

---

## 💡 Proposed Solution

The system uses an interactive GIS map to display village assets according to their geographical coordinates.

Each asset can contain information such as:

- Asset name
- Category
- Location
- Latitude
- Longitude
- Operational status
- Description

Users can select map markers to view asset information and use search and filtering features to find specific facilities.
